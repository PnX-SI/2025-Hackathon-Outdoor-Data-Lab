# Récupération de données Utagawavtt


A contrario de skitour, Utagawavtt ne propose pas d'API pour récupérer facilement les données accessibles via un compte.

Le script proposé est donc très sommaire et n'est pas totalement fonctionnel au vu du temps imparti lors du hackathon pour acquérir ces compétences.
Ainsi les #TODO en commentaires du script propose des pistes, des bouts de code à rédiger pour rendre opérationnel le script.
